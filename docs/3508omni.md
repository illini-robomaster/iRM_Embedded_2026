# DJI-compatible DM3519 chassis (3508omni)

This branch changes the MC02 `eoh_infant` target (`vehicles/Omni/eoh_mc02.cc`).
Other vehicle/example targets retain their existing motor drivers.

The original working software is preserved on `rickxu2/omni` at `d1c785a8`.
This branch requires DJI-compatible motor-controller firmware (DM3519 V41,
C620 protocol); changing the MC02 program alone does not convert the motor
controllers from DM VEL mode.

## CAN mapping

Verified physical IDs viewed from above: front right 3, back right 4,
back left 2, front left 1. Array indices retain the original kinematic order.

| Wheel | Old feedback / command | New feedback | New command slot |
|---|---|---|---|
| Front right M0 | 0x10 / 0x11 | 0x203 | 0x200 bytes 4..5 |
| Back left M1 | 0x12 / 0x13 | 0x202 | 0x200 bytes 2..3 |
| Back right M2 | 0x18 / 0x19 | 0x204 | 0x200 bytes 6..7 |
| Front left M3 | 0x16 / 0x17 | 0x201 | 0x200 bytes 0..1 |

Commands are signed big-endian current counts. Only `yawTask` sends 0x1FF
(yaw, feeder and flywheels share it, feedback IDs 0x205..0x208). There must be
no other sender commanding the 0x200 group.

## Gear ratios (measured 2026-11-01)

Feedback is rotor rpm. `chassis_turn_count` turned each rotor an exact number of
encoder turns and the wheel marks were checked:

| ID | Wheel | Motor | Rotor : wheel |
|---|---|---|---|
| 1 | front left | DM3519 | 268:17 (15.765) |
| 2 | back left | DM3519 | ~7.80 |
| 3 | front right | DM3519 | 268:17 |
| 4 | back right | M3508 | 268:17 |

The earlier 10:1 / 3591:187 assumption made IDs 1/3 run at 63% and IDs 2/4 at
122-128% of the commanded speed (slow front wheels, eccentric spin). ID2's higher
motor current is its lower ratio, not a fault; in wheel torque (current x ratio)
its load matches ID1. ID3 is ~13% above ID1/ID2, ID4 ~60% above.

## Chassis control

Per wheel: command ramp, 10 ms target filter (DM3519s), load feedforward
`sign(w)*static + viscous*w` and a PI (Kp 200, Ki 600/s, integral cap 4000, PI
output 6000, total 8000). The integral only runs once the ramp has settled.
Feedforward is 80% of a free-air fit with the measured ratios (order FR/BL/BR/FL):
static 282/616/553/242 counts, viscous 12.6/13.5/11.6/10.7 counts per wheel rad/s.
Refit with `chassis_wheel_test` (feedforward set to zero) after mechanical changes.

## Power governor and spin

RM2027 0x0202 no longer carries chassis power (bytes 0..7 read zero); only the
buffer energy is sent. The governor scales all wheel targets to keep the buffer
near 35 J (fast-drain cut, proportional cut below target, slow probe back up when
full), so the average power follows whatever limit the referee enforces.
Spin asks for the 40 rad/s wheel cap with live buffer data and 20 rad/s without.
Measured on the ground at 120 W: 20.3 s spin, mean 35 rad/s wheel, mean chassis
13.4 rad/s (128 rpm), minimum buffer 32 J.

## Yaw

`yawTask` (500 Hz) runs the GM6020 in voltage mode: P on the field-frame error,
D on (IMU yaw rate + 6020 speed feedback), and back-EMF feedforward
`550 x 6020 speed` (60-75% of the motor constant). The 6020 speed sign was
checked against its encoder by hand (57/0 samples).

## Safety and diagnostics

- Outputs stay off until a live DBUS link shows swl UP; a link loss (>100 ms)
  disarms and needs UP -> MID again.
- `[IDLE]` (disabled) shows link/arm, yaw, wheel connections and CAN error
  counters; `[CH]` (enabled, 20 Hz) logs per-wheel setpoint/measured/output and yaw.
- Spin statistics (`[LAST SPIN >=3s]`) and an event log (`[EV]`: boot, arm/disarm
  reason, spin start/end, RC link, wheel feedback) live in D3 SRAM4 and survive a
  reset (plugging in the ST-Link resets the board), not a power cycle.

## Test programs

- `chassis_wheel_test`: free-air per-wheel current and speed steps, spin and
  straight patterns, same control chain as `eoh_infant`.
- `chassis_turn_count`: exact rotor-turn moves for gear-ratio checks.
- `dm3519_201_diag`: low-current single-motor diagnostic for ID1.

Build from the repository with the portable tool environment loaded:

```powershell
. '..\embedded-tools\env.ps1'
cmake --build build --target eoh_infant.elf --parallel 8
```
